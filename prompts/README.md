# Course prompts

Copy-paste prompts for every hands-on movie, grouped by chapter. Each prompt works the same in **Claude Code CLI** and **Claude Code Desktop**.

Before an app's first exercise, install its dependencies once:

```bash
cd demos/helpdesk-ai && npm install    # greenfield app (chapters 1-7)
cd demos/orders-legacy && npm install  # brownfield app (chapter 7)
```
